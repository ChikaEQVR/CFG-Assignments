These are the commands I demonstrated in my local repository;
    - git status : to show all the files information added / removed.
    - git branch <new branch> : to create a branch.
    - git add : to add files to a branch.
    - git commit -m "messages" : to commit with meaningful messages.
    - git push -u origin main / git push origin <branch> : 
        to connect the branches for the first time and send the changes from local repo to remote repo.
    - git push : whenever send the changes from local repo to remote repo after the initial push
    - git pull : to get the most up-to-date version of the remote repository in my local repository before I push my latest files.
    - git switch <branch> : to switch to a branch
    - git checkout <branch> : another way to switch to a branch
    - ls : to list files and directories
    - ls -a: to list all files and directories including hidden items like git file
    - :q : to close the editor to carry on
